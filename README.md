# John Murphy — Official Film Composer Website

Official website for **John Murphy**, English film composer creating music for amazing films.

## Features

- **Fullscreen Ambient Hero**: Continuous atmospheric film scoring backdrop with refined Swiss typography.
- **Scoring Philosophy Statement**: Dedicated section outlining John Murphy's cinematic scoring ethos and pillars (*Iconic Themes*, *Visceral Emotion*, *Amazing Films*).
- **Interactive Sequence**: Horizontal mouse-driven frame scrubbing of original motion picture cues (*HeroCentre.mp4*).
- **Music & Film Directory**: Showcase of feature film scores (*28 Days Later*, *Sunshine*, *Snatch*, *The Suicide Squad*, *Guardians of the Galaxy Vol. 3*), official soundtracks, signature sound, and sync licensing.

## Tech Stack

- Semantic HTML5
- Modern CSS (Swiss typography stack, custom CSS variables, responsive clamp scaling)
- Vanilla JavaScript (media playback & mouse-driven frame scrubbing controller)
